# Starting AI Dev Tools Zoomcamp

The materials remain available after the cohort begins.

You do not need to attend at a particular time to use them.

The course is designed for people who want to build while learning. The lectures are recorded, but the live cohort gives the material a rhythm through deadlines, peer projects, and conversations. Participants can also follow the same modules independently.

The 2026 AI Dev Tools Zoomcamp started on August 31. It is a free course at DataTalks.Club about using AI coding tools across the software-development lifecycle. The five modules follow one application from specification through deployment, operations, and coding-agent extensions.

Module 1 begins with the developer workflow. A vague request lets an agent invent missing decisions, so students turn an idea into a specification and small backlog. They add durable project context and separate product management, implementation, and QA. The goal is a repeatable way to direct an agent and verify the result independently.

Module 2 builds a full-stack application. Students create a frontend, define the API with OpenAPI, implement a backend, add SQLite persistence, and test the main behavior. Generated code is treated as a starting point. Students inspect it, run it, compare it with the specification, and write tests.

Module 3 takes the local application outside the laptop. It adds integration tests, Postgres, containers, CI, and deployment to a public URL. The final pipeline gives participants a documented way to test, deploy, and roll back a change.

Module 4 covers operations. Students separate development and production, promote a tested version, and instrument an important request with OpenTelemetry. Metrics, logs, and traces appear in Grafana. An alert represents sustained user impact, and an agent receives a bounded evidence packet to investigate and propose an action. Code outside the model controls what actions are allowed.

Module 5 looks inside the coding-agent workflow. It covers project instructions, MCP, reusable skills, hooks, specialized subagents, plugins, guardrails, and permissions. The emphasis is on capabilities that can work across products rather than one vendor’s name.

The cohort is self-paced in its recordings but has shared deadlines, homework, peer review, and a leaderboard. Registration and course access use the course platform; module materials, code, and requirements live in the GitHub repository. Slack is the place for questions, while Telegram carries announcements. The course FAQ is the first place to search for a recurring technical problem.

The final project must include a frontend, backend, OpenAPI specification, persistent storage, automated tests, containers, a public deployment, and clear run instructions. Students also document how they used AI, reviewed generated code, tested behavior, and handled permissions. Homework is optional for the certificate, but a passing final project and required peer reviews are needed during the live cohort.
